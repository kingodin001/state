# Рисованное колесо 0.18

Оригинальная растровая рамка создана imagegen: фронтальный круг из золота и синего металла с лампочками, прозрачными центром и фоном, без текста, цифр или секторов. Призы используют ранее созданные 27 собственных растровых иконок. Сектора и подписи остаются интерфейсом, согласованным с фактической наградой.

Runtime: `app/src/main/assets/game/art/wheel/frame.webp`, 768×768; сгенерированный PNG масштабирован и сжат без перерисовки. Изображение не нарисовано SVG, CSS или Python.
