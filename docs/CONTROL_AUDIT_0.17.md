# Контроль 0.17.0

База c7521ec (0.16), код версии18. Изменения: 27 рисованных иконок и использование их в общих декоративных элементах; название «Арена»/«В бой» с указанием ИИ в описании; новый график межуровневой рекламы. Карты, последовательность этапов, боевой движок и настройки противников этой версией не заменены.

|---|---|

Изначальный единичный сбой браузерной проверки f13 после перезагрузки при параллельной нагрузке повторно не воспроизвёлся. Проверка расширена быстрыми перезагрузками; сама логика сохранений не менялась.

Модель принятия решений ИИ — собственный компактный JS-симулятор. Совпадение каждого нативного решения, сегментации виртуальных групп, всех множителей интереса и поискаV5 не подтверждено. Проверка кривых, пассивных эффектов, способностей и задержек не является проверкой всех решений. Подробные основания исходной механики — CONTROL_AUDIT_0.16.md.

Production ID РСЯ пустые. Физический Android, фактическое заполнение рекламы, установка поверх прежней APK на телефоне, размещение на REG.RU и отправка в RuStore в этой среде не проверялись и не выполнялись. Серверный комплект подготовлен для загрузки; проверка на устройстве выполняется после добавления трёх собственных ID.
