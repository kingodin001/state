# Проверка версии 0.3.0

Дата: 22 октября 2026 года.

- 40 тестов симуляции, геометрии и экономики пройдены. Новые проверки покрывают постепенный выход 50 бойцов за 4.75 с, сохранение защитников до выхода, общий резерв нескольких приказов, отмену остатка после захвата базы, сохранение численности, отсутствие ускорения очереди, марш при 20 / 30 / 60 / 120 FPS и кадрирование баз.
- Все пять кампаний завершены простой политикой расширения без покупки улучшений: 29.9 / 46.4 / 49.4 / 58.0 / 55.3 секунд симуляции. Политика учитывает доступные, а не уже зарезервированные отряды. Это доказывает проходимость конкретным алгоритмом, но не оценивает сложность для человека.
- Все пять игровых экранов проверены при 360×640, 390×844 и 412×915: видимость стартовых фракций, доступность HUD, полный обзор географии, возврат к боевому виду и перемещение карты.
- Отдельно пройдены реальные жесты: отмена отправки, выбор 25%, удержание стрелки без отправки, отправка после отпускания, постепенный выход и захват, несколько исходных баз, тап по цели с подтверждением на отпускании, сохранение запрета отправки после отпускания одного из двух пальцев.
- Повторно пройдены магазин, подарок, сундук, обмен валют, покупка / экипировка / повышение уровня карточки, сохранение, доход после фона, усиления, операции, пауза и рестарт на трёх размерах экрана.
- Пройден сценарий победы с ускорением только времени в тесте: награды, альбом, открытие следующей кампании и переход. Выпускной код ускорения не содержит.
- В перечисленных сценариях ошибок JavaScript нет. Скриншоты прицеливания, выхода отряда, массовой отправки, пяти карт и экранов коллекции проверены визуально; они не являются скриншотами работающего оригинала.
- Подписанный релиз собран Android Build Tools 35 с Java-компиляцией ECJ, выровнен zipalign. apksigner подтвердил схемы v2 и v3; сертификат SHA-256 совпадает с релизом 0.2.0. Пакет `pro.vymi.terrastorm`, versionCode 3. Проверены предпосылки обновления с сохранением данных; сама установка на телефон не выполнялась.
- Каждый игровой файл внутри APK побайтно совпал с проверенными исходниками. Manifest содержит Android 8.0+, targetSdk 35 и разрешение вибрации; сетевые разрешения не добавлены.

## Итоговый файл

- `TerraStorm-0.3.0.apk`
- Размер: 6911367 байт
- SHA-256: `15f6e583bc9c9aff609f7508f9435da5ea819f5433b885dfc18eac5cf81fbbb4`

## Ограничения

Нет запуска на Android-устройстве или эмуляторе. Системная кнопка возврата, вибрация и конкретный Android System WebView физически не проверены. Исходный State.io 4.4.2 не запускался: точные скрытые параметры и все переходы не измерены. Это не подтверждённая копия 1:1. Полная таблица реализованного, отличающегося и отсутствующего — [REFERENCE_PARITY.md](REFERENCE_PARITY.md).

# Проверка версии 0.1.0

Проверки завершены 22 октября 2026 года (Москва).

- 15 тестов симуляции пройдены: производство, лимит 50, подкрепления, отправка части отряда, несколько источников, захват, столкновения, пауза, способности, условия победы/поражения, специальные базы, поведение AI, полный restart, детерминированность.
- Все пять кампаний завершены автоматической политикой расширения без покупки улучшений. Результаты показывают проходимость, а не оценку сложности для человека.
- Мобильный интерфейс проверен в Chromium на 390×844, 360×640 и 412×915: перетаскивание захватывает территорию, пауза замораживает время, restart восстанавливает исходное состояние, прогресс переживает перезагрузку.
- Проверены меню оформления, командиров, заданий, настроек и карты мира; ежедневная награда выдаётся однократно, улучшение списывает монеты, доход после возвращения из фона выдаётся однократно.
- Дополнительно проверены жест приближения двумя пальцами (не отправляет армию), сброс масштаба и применение подкрепления к своей базе.
- Ошибок JavaScript в этих сценариях не обнаружено.
- Gradle 8.11.1 / Android Gradle Plugin 8.9.2: `assembleDebug` завершился успешно.
- Релизный APK собран напрямую Android Build Tools 35.0.0, выровнен zipalign и подписан новым RSA-ключом 3072 bit. Проверка apksigner успешна для v2 и v3.
- В APK проверены пакет, launchable Activity, minSdk 26, targetSdk 35 и присутствие DEX/ресурсов. Все пять игровых файлов в APK побайтно совпали с проверенными исходниками.
