# Проверка версии 0.2.0

22 октября 2026 года (Москва).

- 31 тест симуляции и экономики пройден: прежние 15 боевых проверок и 16 новых проверок коллекции, миграции, цен, атомарных покупок, фрагментов, сундуков, дневных наград, альбомов и четырёх приказов лидеров.
- Все пять кампаний завершены автоматической политикой расширения без улучшений.
- Интерфейс проверен на 390×844, 360×640 и 412×915: магазин, бесплатный подарок, сундук, обмен валюты, покупка/выбор бойца, сохранение после перезапуска, обычные улучшения, захват территории, пауза, рестарт, приказ лидера и доход после возвращения из фона.
- Отдельно проверены повышение уровня карточки, все полноэкранные разделы, приближение двумя пальцами без отправки армии, расход и применение усилений, запуск ежедневной операции за припасы.
- Сражение первого уровня пройдено через интерфейс с ускоренным временем симуляции в тесте. Подтверждены экран победы, монеты/кристаллы/сундук/альбом, разблокировка и переход к следующей кампании.
- В проверенных сценариях ошибок JavaScript нет.
- Gradle `assembleDebug` завершился успешно.
- Итоговый релизный APK собран Android Build Tools 35, выровнен zipalign, проверен apksigner (v2 и v3).
- Сертификат подписи побайтно совпал по SHA-256 с сертификатом релиза 0.1.0. Пакет прежний `pro.vymi.terrastorm`; versionCode повышен до 2. Проверены предпосылки установки обновлением, но сама установка на телефон не выполнялась.
- Все игровые файлы внутри APK, включая новые растровые иллюстрации, совпали с проверенными исходниками.

## Ограничения

Android-устройство и эмулятор в сессии недоступны. Установка, нативная вибрация, системная кнопка «назад» и конкретный Android System WebView на телефоне пока не проверены. Оригинальная State.io 4.4.2 не запускалась; точное совпадение каждого экрана и поведения с работающим оригиналом не подтверждено. Сетевой PvP, серверные события, реальные платежи и рекламные SDK не реализованы. Пять кампаний и локальная коллекция — собственная реализация.

# Проверка версии 0.1.0

Проверки завершены 22 октября 2026 года (Москва).

- 15 тестов симуляции пройдены: производство, лимит 50, подкрепления, отправка части отряда, несколько источников, захват, столкновения, пауза, способности, условия победы/поражения, специальные базы, поведение AI, полный restart, детерминированность.
- Все пять кампаний завершены автоматической политикой расширения без покупки улучшений. Результаты показывают проходимость, а не оценку сложности для человека.
- Мобильный интерфейс проверен в Chromium на 390×844, 360×640 и 412×915: перетаскивание захватывает территорию, пауза замораживает время, restart восстанавливает исходное состояние, прогресс переживает перезагрузку.
- Проверены меню оформления, командиров, заданий, настроек и карты мира; ежедневная награда выдаётся однократно, улучшение списывает монеты, доход после возвращения из фона выдаётся однократно.
- Дополнительно проверены жест приближения двумя пальцами (не отправляет армию), сброс масштаба и применение подкрепления к своей базе.
- Ошибок JavaScript в этих сценариях не обнаружено.
- Gradle 8.11.1 / Android Gradle Plugin 8.9.2: `assembleDebug` завершился успешно.
- Релизный APK собран напрямую Android Build Tools 35.0.0, выровнен zipalign и подписан новым RSA-ключом 3072 bit. Проверка apksigner успешна для v2 и v3.
- В APK проверены пакет, launchable Activity, minSdk 26, targetSdk 35 и присутствие DEX/ресурсов. Все пять игровых файлов в APK побайтно совпали с проверенными исходниками.

Браузерная проверка не подменяет такую проверку. Показанного в оригинальном APK поведения всех серверных функций здесь нет; сравнение с работающим оригиналом на одном устройстве не проводилось.
