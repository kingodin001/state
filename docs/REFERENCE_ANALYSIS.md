# Анализ предоставленного State.io 4.4.2

Изучен файл `State.io+—+Conquer+the+World_4.4.2_APKPure.xapk`. Это XAPK из двух APK: `io.state.fight.apk` и `config.arm64_v8a.apk`. В манифесте XAPK: пакет `io.state.fight`, версия 4.4.2 (341), минимальный SDK 25, целевой SDK 36. Общий размер файла около 218.6 MB.

## Что непосредственно обнаружено в файлах

- Unity, IL2CPP, отдельные наборы Addressables для карт и интерфейса.
- В наборах карт: США, Европа, Африка, Аравия, Индия, Китай, Италия, Великобритания, Корея, Япония, Океания, Латинская Америка; отдельные варианты обучения и боевых механик.
- В обучающих объектах: последовательность «атаковать нейтральную базу», «атаковать противника», выбор нескольких исходных баз; стартовые гарнизоны 5 / 10 / 15 и лимит 50.
- В параметрах обучения: нейтральное производство 0, производство активных гарнизонов 1.0; на некоторых объектах свои переопределения.
- По именам компонентов и полям: отправка части отряда, подкрепления, волны бойцов, столкновения бойцов, визуальное размещение гарнизонов.
- Обнаружены параметры и элементы интерфейса щита, дополнительных бойцов, башен, зон замедления, тумана войны и специальных эффектов.
- По именам подсистем: улучшения стартовых войск и производства, оформление баз/бойцов/цветов, лидеры и навыки, задания, ежедневные операции, рейтинговый режим, награды, покупки, реклама и аналитика.

Обнаружение имён компонентов само по себе не доказывает, что каждый из них включается при первом запуске конкретного пользователя: часть функций управляется конфигурацией, прогрессом и сервером. Игра из XAPK на Android здесь не запускалась. Анализ данных не равен наблюдению всех экранов в работающем оригинале.

## Визуальная система

Референс использует простую географическую карту, однотонные цветные территории, белые границы, контрастные числовые маркеры и множество небольших бойцов. Владение читается по цвету; численность — по счётчику; наступление — по направлению потока. Основные решения воспроизведены собственным кодом и собственной векторной графикой. Публичные изображения ранних версий дополнительно использовались для понимания расположения меню, но не включены в приложение.
