# Compact port 0.8.0 — состояние и границы

Восстановлен после двух прерываний и очистки временных рабочих файлов. APK сохранена отдельно до завершения синхронизации исходников. Версия 0.8.0, pro.vymi.terrastorm, code 8, прежний сертификат. APK 20 332 531 байт; контрольная сумма и проверка подписи/ZIP в release-0.8.0.json.

**Проверено:** 51 тест модели/данных/транзакций/сохранений; внутри одного теста — 161 нативный арифметический случай. Браузерные сценарии на 360×640, 390×844 и 600×800: запуск, основные разделы, три сундука, фрагменты/улучшение, выбор бойца, пять стилей, наклейки, отправка отряда, пауза/рестарт, запрет зума, перезагрузка сохранения, арена с ботом. Ошибок JS и загрузки ресурсов нет. Подпись v2/v3, прежний сертификат, полный ZIP CRC, версия/пакет и побайтное совпадение всех 1192 игровых файлов APK с деревом assets проверены. Физический Android недоступен; стабильность запуска на телефоне пока не подтверждена.

Старые expansion/parity/stages/progression тесты оставлены как исторические: они ожидают предыдущий цикл карт, обучения, числа улучшений и выдуманную способность Маршала. Они не включены в актуальный набор и не изменялись ради формального прохождения.

**Воспроизведение:** reference_reader.py читает конфигурации через декларации Cpp2IL 2022.1.0-pre-release.21 (metadata39, Unity6000.3.13f1), исправляя выравнивание m_Enabled, векторы и managed reference registries. export_compact_reference.py экспортирует whitelist игровых конфигураций и WebP/SVG, import_reference.py — геометрию и камеры. source_math_oracle.py использует отдельно предоставленный libil2cpp.so только для узкого сравнения формул. prepare_reference.py раскрывает компактный visual pack перед сборкой. Исходные исполняемые файлы и ключ подписи не хранятся в репозитории.

Это проверяемая компактная адаптация, не точная копия всех функций и не финальная публикационная сборка RuStore. Остались полная сверка меню/AI/пассивных навыков, собственные иллюстрации и реальная проверка Android.
