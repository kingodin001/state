# Рисованные значки 0.17

27 отдельных иллюстраций созданы image_gen.imagegen по текстовым описаниям, с прозрачным фоном. Стиль: объёмные округлые предметы, рисованные градиенты, кобальтовый синий и тёплое золото, яркие блики, мягкие фиолетовые тени, ясный силуэт для маленького значка. Это растровые изображения, не нарисованные программой геометрические значки.

Варианты: золотой доллар; розовые кристаллы; видеобилет; энергокапсула; звезда; сейф с часами; командир на ровере; колесо; мишень; кубок; мечи со щитом; календарь; корзина; командир с бойцами; компас; крылатый щит; альбом карточек; шестерёнка; солдат с флагом; казарма; башня; замок с плюсом; ускорение производства; быстрый солдат; три сундука.

Для APK исходные PNG уменьшены без перерисовки до 384px и упакованы в WebP, quality92, alpha-quality100. Имена, SHA256 исходных и игровых файлов, ссылки на исходные изображения зафиксированы в art/interface/generated-manifest.json. Активный TerraIdentity.file возвращает только WebP. Сохранённый старый SVG-набор не используется интерфейсом.

Общие декоративные значки модальных окон — трофей, отряд, звезда, щит, подарок и другие — показывают те же новые растровые иллюстрации. SVG-контейнер здесь сохраняет прежний размер и расположение в HTML, а содержимым является сгенерированная картинка. Простые управляющие символы закрытия, паузы и стрелок остаются управляющими символами.

Расположение навигации и существующие изображения персонажей боя не заменялись. Изменения интерфейса не являются заявлением о происхождении всех остальных материалов игры или гарантией решения модерации.
