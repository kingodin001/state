# TerraStorm 0.13.0 — source building activation, predictive AI, ad-only prebattle

This is an incremental gameplay correction, not a claim of full native/pixel equivalence.

The source map geometry and campaign configuration are unchanged byte for byte. All 200 initially exposed encounters follow the extracted initial/repeating funnels. Level 11 remains the final Africa stage from the source APK, not a generated replacement.

The import had included disabled alternative Building components as real populations. Seventy-four disabled objects are now masked using their source activation state across 57 maps/arenas. Level 11 has 11 active populations, including two real turrets, instead of 13 with overlapping counters. Turrets use the serialized radius of 52 map units rather than the former invented 135; neutral and empty turrets operate according to source flags. Timing uses the serialized rotation/ray/end phases, but the exact native coroutine sequencing is not yet established.

The source campaigns now use predictive V3/V4/V5 decisions instead of the old distance/random heuristic. Decisions examine combinations of source bases, full/half commands when enabled, source trace settings, capture-force gates, configured limits and source score contracts. A wait command competes with attacks; friendly defense requires an incoming hostile group. V5 samples its configured bounded candidate budget. Forecast production does not multiply the actor rate twice or clip above-cap reinforcements. This aggregate predictor is not a byte-equivalent port of the native scaled group simulator. Native debut profiles, V5 reaction scheduling/intersection and interest updates, aggression interpolation and some extrapolation details remain open. Do not call the whole AI identical.

Source battles now carry fractional frame time into a fixed 40 Hz simulation. Previously, 60/120 FPS introduced extra variable steps and changed collision/RNG outcomes. A recorded sequence of ordinary commands wins level 11 at 20, 40, 60 and 120 FPS, with 10 starting-unit and 5 production upgrades, no ads, no hero and no injected ownership/results. The upgrade cost is below the rewards of the first ten encounters. This establishes passability of that scenario, not guaranteed victory with every strategy or upgrade state.

Prebattle boosters are granted only by a confirmed rewarded-video completion for the pending battle. The dialog has no stock checkbox or gem purchase. Dismissal/failure grants nothing; leaving invalidates pending rewards; restarting requires fresh videos. Existing stock and currencies are unchanged. With the production ad IDs still empty, these buttons are unavailable and the player can start without bonuses. The real SDK is already in the unchanged 0.12 host; no simulated ad grant is shipped.

Validation: 103 Node tests pass, including map integrity, disabled buildings, turret configuration, retargeting, source passives, ad session lifecycle, AI state isolation over 200 encounters and the four-frame-rate level-11 replay. Browser integration checks the native ad bridge callbacks, failed videos, duplicate callbacks, actual extra-base application and fresh-video requirement. Battlefield checks run at 360×640, 390×844 and 600×800. Release UI checks cover transparent artwork, seven own leader assets, disabled no-ID bonus buttons, stock/currency preservation and reload.

The asset-only updater is guarded by the known 0.12 APK hash and refuses Android Java/resource/manifest/dependency changes. All 1,212 packaged assets match the working files; classes.dex and resources.arsc match 0.12 byte for byte. Version code is 14; V2/V3 signatures use the existing certificate. A full Gradle release remains required for native changes. No physical Android device or emulator is available in this environment; Android launch has not been tested here.

Remaining requested work includes the native AI details above, complete ability selection/effects, all window/layout comparison entries in the existing UI audit, and animations. No blanket claim that these are already identical is supported by this release.
