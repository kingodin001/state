# Проверка точного переноса и лимита 40 МБ

29 октября 2026. Пользователь повторно отклонил отдельную симуляцию и меню 0.8.0. Требование: сохранить исходную игру, меню и уровни, убрать чужую рекламу, затем менять значки; APK не больше 40 МБ. Это требование в 0.8.0 не выполнено. Состав игры и выпуск APK в этой проверке не менялись.

Вновь измерен предоставленный State.io 4.4.2 XAPK. Использована только ARM64-архитектура. В минимальную проверяемую группу runtime включены libil2cpp.so, libunity.so и libmain.so; дополнительные нативные SDK исключены. Все Java-классы из сравнений core+content исключены, а не выданы за успешно удалённые из работоспособного приложения.

| Группа | Исходные байты | В исходных ZIP | XZ/LZMA2 preset 6 |
|---|---:|---:|---:|
| Основные три библиотеки | 153 556 856 | 42 774 497 | 26 167 604 |
| Unity + Addressables | 104 808 991 | 50 380 875 | 36 341 108 |
| Все DEX, включая SDK | 116 209 508 | 113 373 486 | 33 205 412 |

Runtime и исходные игровые файлы вместе после XZ: **62 508 712 байт**, без DEX, дополнительных SDK и Android-оболочки.

Дополнительный эксперимент: 88 UnityFS bundles сначала распакованы/пересобраны без внутреннего сжатия, затем все 1695 игровых файлов сжаты общим XZ-потоком. Игровой контент сократился до **33 081 568 байт**; с основными библиотеками получается **59 249 172 байта**, всё ещё без Java и оболочки. При такой пересборке требуется корректировка CRC/hash/размеров в каталоге Addressables. Совместимость на Android не проверена.

Это не математическое доказательство невозможности любых будущих оптимизаций. Но проверенные варианты прямой упаковки оригинала превышают заданный предел ещё до включения всех обязательных компонентов. XZ-файлы являются исследовательскими архивами, а не готовыми APK; им нужен дополнительный механизм распаковки. Удаление SDK из монолитного IL2CPP и DEX с сохранением JNI, отражения и порядка загрузки не выполнено и не считается безопасным по одному размерному анализу.

Наиболее надёжный путь к исходным экранам и логике при жёстком лимите — исходный Unity-проект с удалением ненужных пакетов и повторной компиляцией/оптимизацией. Другие варианты требуют изменения требования: больший APK либо отдельная загрузка игрового контента после установки. Последний вариант уменьшает APK, но не общий объём скачивания/установки.

Первоначальный Unity-тест 0.7.0 вылетал у пользователя; причина не установлена без журнала Android. Он не переобозначен как работающий результат. Компактная 0.8.0 остаётся адаптацией, а не точной копией. Новая APK в рамках этой размерной проверки не выпускалась.

Данные: [native-size-feasibility.json](native-size-feasibility.json). Воспроизведение: `scripts/measure_native_payload.py --base BASE.apk --arm64 ARM64.apk --out OUT`, затем `scripts/measure_native_content_repack.py --base BASE.apk --out OUT/unpacked.xz`. Для второго нужен UnityPy. Скрипты читают предоставленные APK и не включают их в репозиторий.
