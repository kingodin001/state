# Компактная 0.10.0: фактический статус

Продолжение работающей на телефоне пользователя 0.8.0. Java Activity, пакет `pro.vymi.terrastorm`, Android WebView и ключ подписи сохранены. Нативная ветка Unity 0.9.x не используется. Это промежуточная реализация, а не завершённая точная копия и не готовый релиз RuStore.

## Что изменено

| Область | Реализовано | Граница проверки |
|---|---|---|
| Кампания | Извлечённые начальная и повторная последовательности; 43 этапа в каждой, исходные карты/настройки; продолжение после 200; ленивое хранение | Проверены ссылки, геометрия, сохранения до этапа 1000; исходный runtime не воспроизведён целиком |
| Камера | Для исходных уровней полный viewport и сохранённые центр/полувысота; ручного зума нет | Все активные центры первых 200 этапов помещаются на трёх тестовых размерах |
| Бойцы и базы | 64 исходные текстуры с реальной прозрачностью вместо грубых SVG из треугольников атласа | Экспорт пикселей; скриншотная сверка с запущенным оригиналом не выполнена |
| Стрелка | Исходный спрайт `arrow`, горизонтальные края 32/197, растяжение центральной части | Толщина, интерполяция и переходы анимации ещё не подтверждены оригинальным исполнением |

## Незавершённое

Все 99 исходных окон перечислены в [ui-parity-0.10.csv](ui-parity-0.10.csv), а исходные 746 интерактивных узлов — в [reference-interactive-nodes.json](reference-interactive-nodes.json). Ни одна строка не помечена как проверенная пиксель в пиксель. Архив `reference-content/ui-layout.zip` сохраняет исходную структуру и графические ссылки для продолжения переноса.

Кроме указанных границ, остаются отдельные ежедневные операции с полным набором модификаторов, RegionRush по стадиям гонки (имеющийся режим 90 секунд отличается), алгоритмы/доступ к колесу, сезонные альбомы, полный idle/quests, анимации окон, пассивные навыки и онлайн-интеграции. Они не выдаются за перенесённые только потому, что похожая кнопка уже существует.

## Воспроизведение и проверки

`python3 scripts/prepare_reference.py`, `npm test`, затем `npm run test:ui` с установленными Playwright/Chromium. Сборка — `bash scripts/build.sh` с Android SDK 35 / JDK17 и ключом вне репозитория. `scripts/verify_compact.py` проверяет совпадение всех игровых файлов внутри APK, CRC, нормальный пакет, версию 0.10.0 / code11, прежний сертификат и размер ≤59 000 000 байт.

Android Activity не менялась относительно 0.8.0. Это снижает риск возврата ошибки Unity, но не заменяет запуск нового APK на устройстве. Физический Android и запущенный исходный APK в этой среде недоступны; холодный/повторный запуск и пиксельная сверка на телефоне не подтверждены.

`export_source_meta.py` публикует только белый список игровых конфигураций и составов товаров. Полную промежуточную выгрузку SDK-конфигураций публиковать нельзя. `export_source_ui.py` требует декларации Cpp2IL с обработчиками `attributeanalyzer,attributeinjector`, иначе пропадают сериализованные поля.
