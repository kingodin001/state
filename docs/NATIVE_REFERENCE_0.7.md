# Прямой перенос Unity: тест 0.7.0

28 октября 2026. Пользователь отклонил 0.6.0, потому что она воспроизводила лишь часть данных на другом движке и оставляла собственные меню и баланс. Для проверки другого подхода подготовлен отдельный пакет **`pro.vymi.terrastorm.reference`**, версия **0.7.0-unity-test**. Он устанавливается рядом с `pro.vymi.terrastorm`, не читает и не заменяет её сохранения.

Это перепаковка предоставленной Unity-сборки с ограниченными изменениями ресурсов. Она не объявляется самостоятельным движком Terra Storm или готовой игрой для RuStore. Оригинальные проверки покупок, лицензий и прав не обходились. Запуск на Android в этой среде не выполнен; возможность пройти исходную загрузку без сетевых служб пока не подтверждена.

## Проверка файлов

Сохранены все **7 Unity-сцен**, **88 Addressables bundles**, **15 исходных DEX** и все библиотеки ARM64. В исходных данных находятся **63 848 объектов**; ни один не удалён. Добавлены две текстуры для новых векторных логотипа и стрелки.

Из исходных объектов изменены ровно **66 Sprite**, **2 SpriteAtlas** и **1 PlayerSettings**. Это логотип, стрелка, 64 варианта силуэтов и название приложения. Все остальные объекты, в том числе **16 949 MonoBehaviour**, сравнивались по исходным сериализованным байтам. Ни один игровой/UI-компонент не переписан. Исходное разбиение sharedassets2 на split-файлы сохранено, неоднозначной пары «merged + split» в пакете нет.

Новый APK имеет корректную ZIP-структуру; подпись v2/v3 проверена ключом Terra Storm. Контрольные суммы и подробный список изменений: `native-reference/preservation-summary.json`. Это проверки упаковки и сохранности данных; прежние браузерные тесты WebView не выдаются за проверку этой Unity-сборки.

## Что остаётся незавершённым

- Реальный запуск, исходная загрузка без сети, сенсорное управление и прохождение на Android.
- Замена остальной исходной графики, текстов, звуков и служебных ссылок на собственные.
- Собственные рекламные, платёжные и сетевые службы и соответствующие пользовательские сценарии.
- Проверка прав на использование исходных исполняемых файлов и оставшихся ресурсов перед публикацией.

Текущая задача выполнена только как технический перенос для проверки. Полностью проверенный клон со всеми собственными данными пока не готов. В RuStore ничего не отправлялось.
