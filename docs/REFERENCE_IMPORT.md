# Игровой цикл по данным референса — 0.6.0

28 октября 2026. Применён согласованный подход BusSpark: собственная оболочка, коллекция и арт; восстановленные из предоставленного APK схемы и правила боя. Текущая кампания больше не использует случайное размещение армий на 20 картах Natural Earth.

Импорт: **51 схема с вариантами, 2 136 территорий и 178 участков**. Первые два задания — исходные обучающие схемы с тремя и четырьмя областями; далее используются полноценные многостадийные карты, в том числе США, Европа, Италия, Африка, Аравия, Индия, Китай, Япония, Корея, Британия, Латинская Америка и Океания.

## Что восстановлено из файлов

| Данные референса | Применение в нашем движке |
| --- | --- |
| Векторные сетки территорий, преобразования родителей и координаты баз | Контуры и положения перенесены в `reference-levels.js`; собственные модели баз и бойцов рисуются в этих координатах |
| Разбиение на участки и их порядок | Следующий участок активируется после завершения текущего; прежние базы не дают бесконечную армию на новом участке |
| Position / Size камер уровня и каждого участка | Камера следует участкам автоматически с переходом 0.85 с; корректируется только для доступности счётчиков на разных пропорциях телефона. Ручного zoom / pan нет |
| SpawnType и точки появления | Свои и вражеские стартовые позиции берутся из префабов; используются максимум три вражеские фракции, лишние потенциальные точки остаются нейтральными |
| Явные StartAmount / SpawnSpeed / LimitAmount | Переопределения сохранены, включая нулевое производство обучения. Старт первого обучения: 15 / 5 / 5 до наших бонусов; лимит 50 |
| Порядок целей обучения и скрытые базы | Новая цель появляется после предыдущего захвата; нельзя отправить отряд к ещё скрытой базе |
| Башни и особые здания в схемах | На карте работают 25 позиций башен, 76 позиций подкрепления и 39 щитов, включая четыре усиленных щита |
| Дополнительные бойцы и запас щита | +50 бойцов при первом захвате, щиты с запасом 50 / 100 |
| Замедляющие / ускоряющие зоны | 41 зона ×0.5 и 18 зон ×1.5 с координатами из схем; влияют на марш |

Числа зданий относятся к записям всех 51 схемы, включая повторяющиеся варианты, а не к одному прохождению карты. Код импортера: `scripts/import_reference.py`; исходный XAPK и его исполняемые файлы в репозиторий не добавлены. Контроль источника и состав схем: [reference-import-summary.json](reference-import-summary.json).

## Что остаётся нашим

200 заданий составлены из 51 восстановленной схемы. После двух обучений оставшиеся схемы повторяются по кругу с развитием противника. Это наш порядок кампании; серверный порядок State.io из APK не установлен. Не заявляются 200 уникальных географических карт или буквальное равенство исходной сложности.

Наши: название, герои, иллюстрации, меню, магазин, коллекция из 84 карточек, экономика, задания, наклейки и офлайн-события. Сохранения, купленные улучшения и выбранные оформления прежних версий сохраняются. Стартовые значения без явного переопределения, AI, резервирование войск, столкновения, интервалы выхода, движение, трактовка бонусов и анимация перехода реализованы нашим движком. Прямого переноса Unity-кода нет. Исходные значения, которые доступны только с сервера или во время игры, не выдумываются как «извлечённые».

Боевой цикл: выбрать свои базы → указать цель → постепенный выход отряда → марш и столкновения → захват / защита → завершение участка → следующий участок с его стартовыми условиями → одна награда за всю карту. Двумя пальцами приказ отменяется; камера вручную не перемещается. Предпросмотр и бой используют один расчёт гарнизонов.

## Проверка

- 76 проверок движка / мета-систем / импорта, включая порядок обучения, заблокированные будущие участки, нулевое производство, щиты, зоны и финальную победу.
- Тестовый игрок проходит все 200 заданий с заработанными монетами и обычными улучшениями, без подмены ресурсов и мгновенных побед.
- Все 178 участков проверены математически на трёх пропорциях экрана; 600 начальных расстановок кампании отрисованы через реальный интерфейс на 360×640, 390×844 и 412×915.
- Полная четырёхучастковая карта пройдена в браузере через кнопки / указатель: переходы камеры, отсутствие промежуточной награды, одна итоговая победа и открытие следующего задания. Только время симуляции в этом тесте ускорено.
- Проверены магазин, три сундука, арсенал, события, сохранение, отмена жестов, выбор доли, несколько баз, пауза и рестарт.

Это адаптация по данным APK, проверенная в Chromium. Исходный Unity-APK и наша сборка на физическом Android здесь не запускались. Попиксельное совпадение, равенство AI и всех серверных функций не заявляются. Реклама, платежи и сеть из референса не переносятся.
