# Подключение рекламы через REG.RU

Приложение: pro.vymi.terrastorm. Название: «Стейт Шторм: Захват территорий».

1. В РСЯ откройте ваше Android-приложение и создайте три блока: адаптивный баннер, межстраничная реклама, видео с вознаграждением. Нужны три идентификатора вида R-M-… . Один видео-блок можно использовать для нескольких добровольных наград. Позже их можно разделить по статистике, заменив четыре rewarded_* поля на разные ID.
2. В server/state/ads.json впишите banner, interstitial и четыре rewarded_* поля. Можно выполнить scripts/set_ad_ids.py с параметрами --banner, --interstitial, --rewarded. Никакие пароли РСЯ или REG.RU в JSON не нужны.
3. В файловом менеджере хостинга games-api.vymi.pro загрузите содержимое server/state в папку state внутри корня сайта. Не заменяйте корень сайта и существующие файлы других игр.
4. Проверьте, что https://games-api.vymi.pro/state/ads.json открывается как JSON с вашими ID, а https://games-api.vymi.pro/state/privacy.html — как страница политики. Перенаправление URL настроек не допускается: нужен прямой ответ 200 по HTTPS с application/json.
5. Перезапустите установленную игру. Она получит ID с сервера без новой APK. При возвращении в приложение настройки обновляются не чаще раза в 15 минут. Если сеть недоступна, используется последняя корректная конфигурация; сама игра работает офлайн.

Баннер находится в меню и скрывается в бою. Межстраничная реклама запрашивается после побед на уровнях 18, 20, 22…80, затем на каждом уровне начиная с 81-го, при переходе из результата. Если игрок уже посмотрел видео ×3, следующая межстраничная реклама для этого результата пропускается. Уровни 1–17, поражения и сам бой не прерываются рекламой. Общего дневного лимита рекламных просмотров нет. Отдельные награды сохраняют свои правила: мгновенный доход выдаётся дважды в сутки, усиление выбирается один раз на бой. Усиления перед боем действуют на один бой.

Для отключения всей рекламы установите enabled=false. Не меняйте schemaVersion или packageName. При ошибочном/неполном документе приложение сохранит предыдущие корректные настройки.

Перед публикацией проверьте реальные показы и возврат в игру на Android. В карточке РСЯ укажите сайт разработчика, где размещён app-ads.txt. Существующий app-ads.txt нельзя заменять без проверки издательского ID вашего текущего аккаунта РСЯ. Для обновления потребуется именно ваш publisher ID/строка РСЯ, не ID рекламного блока.


## Заполнение и загрузка

Из корня распакованного комплекта, при установленном Python 3:

```sh
python3 scripts/set_ad_ids.py --banner R-M-ВАШ-ID --interstitial R-M-ВАШ-ID --rewarded R-M-ВАШ-ID
```

Вставьте каждый полный ID из РСЯ вместо примера. Не используйте один ID для разных форматов. Все четыре поля rewarded_* могут содержать один ID видео с вознаграждением. Загрузите только содержимое `server/state/`, включая скрытый `.htaccess`, в папку `state` внутри корня сайта `games-api.vymi.pro`. APK, скрипты и тексты карточки на сервер не загружаются. PHP и база данных не нужны. Физический путь корня сайта зависит от настроек хостинга — выбирайте корень именно этого поддомена.

После загрузки:

```sh
python3 scripts/check_ad_server.py
```

Это проверяет прямой ответ HTTP 200, Content-Type, схему и ID. Проверка не показывает рекламу. Для аварийного отключения установите `enabled: false`. Изменение применяется после успешного обновления: повторный запрос не чаще раза в 15 минут, сетевые таймауты 5 секунд. Удалять данные игры не нужно.

## Проверка перед RuStore

1. Установите APK поверх предыдущей версии, проверьте сохранения и повторный запуск.
2. Баннер — в меню, в бою скрыт.
3. Добровольное видео: награда после завершения; раннее закрытие без награды; отсутствие объявления; возврат из рекламной ссылки.
4. Переходы после побед: 17→18 без межстраничной рекламы, 18→19 с запросом, 19→20 без, 80→81 и 81→82 с запросами. Нет доступной рекламы — игра продолжает работать.
5. В RuStore загрузите APK, иконку и минимум три снимка `screenshots/`, скопируйте `RUSTORE_CARD.json`. Укажите наличие рекламы и фактические данные SDK. Сначала разместите публичную политику.

Официальные инструкции: https://ads.yandex.com/helpcenter/en/dev/android/rewarded ; https://ads.yandex.com/helpcenter/en/dev/android/interstitial ; https://ads.yandex.com/helpcenter/en/dev/android/adaptive-sticky-banner ; https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication .
