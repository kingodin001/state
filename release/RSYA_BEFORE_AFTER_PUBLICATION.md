# РСЯ до и после публикации StateStorm

Приложение: «Стейт Шторм: Захват территорий», Android, пакет `pro.vymi.terrastorm`.

1. Сейчас в РСЯ добавьте ещё не опубликованное Android-приложение. Оно получит тестовый статус. Создайте в нём три собственных рекламных блока: адаптивный баннер, межстраничный и видео с вознаграждением. Нужны именно Ad Unit ID вида `R-M-…`, а не общий ID приложения.
2. Впишите эти ID в `server/state/ads.json`: баннер в `banner`, межстраничный в `interstitial`, ID видео — во все четыре `rewarded_*` поля. Установите `enabled: true`. Загрузите файлы `server/state/` на REG.RU в каталог `state` корня поддомена `games-api.vymi.pro`. Адрес настройки для APK: `https://games-api.vymi.pro/state/ads.json`. Подробная инструкция в `REG_RU_SETUP.md`.
3. Проверьте APK на телефоне. Пока приложение имеет тестовый статус или проходит модерацию РСЯ, показы тестовые: дохода от них нет. Игровая награда за успешно завершённое тестовое видео позволяет проверить работу кнопок.
4. После публикации RuStore откройте **то же приложение в РСЯ**, добавьте магазин RuStore, публичную ссылку карточки и тот же пакет `pro.vymi.terrastorm`. Подтвердите владение способом, предложенным РСЯ. Для RuStore Яндекс использует контакты разработчика из описания карточки; можно подтвердить кодом на доступную вам почту либо через файл `app-ads.txt` на указанном сайте.
5. После подтверждения и успешной модерации статус станет активным и ваши блоки начнут показывать настоящую рекламу при доступном заполнении. Если с самого начала использовались собственные `R-M-…` ID, менять их в APK из-за публикации не нужно. Обновлять APK только для включения рекламы тоже не нужно. Если использовались демонстрационные ID, замените их своими на сервере: демонстрационные блоки сами в доходные не превращаются.

Сейчас production ID в комплекте пустые, конфигурация не размещалась на вашем сервере. Ключ подписи в архив не включён. При временной недоступности рекламы обычный бой доступен; неполный просмотр не выдаёт награду.

Политика показов: баннер в меню; добровольные видео для бонусов/награды/смены условия операции; межстраничная после побед 18,20,…,80, затем после каждой победы с 81-го. Поражение и бой не прерываются. После видео×3 второй показ на том же результате пропускается.
