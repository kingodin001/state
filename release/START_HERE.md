# Стейт Шторм: Захват территорий — 0.14.0

В архиве: подписанная APK, иконка512×512, файлы для сайта, описание RuStore и отчёт проверки.

Установка: StateStorm-0.14.0-RuStore.apk. Пакет pro.vymi.terrastorm и ключ подписи сохранены; версия имеет код15. Сохранения рабочей компактной версии используют прежнее хранилище.

Для рекламы создайте в РСЯ три Android-блока: адаптивный баннер, межстраничный и видео с вознаграждением. Их ID вида R-M-… нужно вписать в server/state/ads.json и загрузить папку state в корень сайта games-api.vymi.pro. Подробности — REG_RU_SETUP.md. Новая APK при замене ID не нужна. В комплекте ID пустые: реальные объявления появятся только после настройки сервера и доступности блоков РСЯ.

Баннер показывается в меню и скрыт в бою. Добровольное видео используется для наград. Межстраничные объявления запрашиваются после побед на уровнях5,7,9… при выходе из результатов, в том числе системной кнопкой «Назад». После видео×3 повторная реклама на этом переходе пропускается.

В RuStore используйте иконку state-storm-icon-512.png и тексты RUSTORE_CARD.json. Политика предусмотрена по адресу https://games-api.vymi.pro/state/privacy.html; сначала её нужно разместить. Архив не содержит ключ подписи или пароли.

Подтверждено:107 игровых тестов,4 проверки Android-конфигурации рекламы, сценарии меню и рекламы в браузере. Настоящий запуск и рекламные показы на Android в этой среде не проверялись. Перед отправкой на модерацию требуется проверка на телефоне с вашими ID. Изменения меню и оставшиеся отличия от исходной игры перечислены в MAIN_MENU_AUDIT_0.14.md; полное совпадение всех механик и окон не заявляется.
