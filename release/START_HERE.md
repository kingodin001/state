# Стейт Шторм: Захват территорий — 0.19.0

Комплект содержит подписанную APK, иконку 512×512, снимки готовой сборки, файлы сервера, инструкциюREG.RU, карточкуRuStore и результаты проверки. Пакет pro.vymi.terrastorm, versionCode20, прежний сертификат и сохранения.

Камера меню теперь использует настройки предварительного просмотра исходной карты. Обычное движение войск замедлено вдвое относительно 0.18, ускорение×2 остаётся отдельным усилением. Видны самолёты подкреплений/диверсии, бомбы с предупреждением и таймером, взрывы. Бомбардировка и десант — условия ежедневных операций; в обычный бой случайные бомбы не добавлялись. Исходная геометрия и очередь уровней сохранены.

Межстраничная реклама: после побед 18,20,22…80, затем после каждой победы с 81-го. Сам бой и поражения не прерываются. После добровольного видео×3 второй рекламный показ для того же результата пропускается. Баннер — в меню; видео за награду — по выбору игрока. Смена условия операции использует подтверждённое видео rewarded_bonus; отмена ничего не меняет.

Для REG.RU нужны три собственных блока РСЯ: баннер, межстраничный, видео с вознаграждением. Заполните server/state/ads.json и разместите содержимое server/state/ в каталоге state корня games-api.vymi.pro. См. REG_RU_SETUP.md. ID в комплекте пустые. При сменеID новыйAPK не нужен.

Для RuStore подготовлены APK, state-storm-icon-512.png, screenshots/ и RUSTORE_CARD.json. Сначала разместите политикуконфиденциальности и проверьте запуск, обновление, повторный запуск и настоящие рекламные показы на телефоне. Архив не содержит ключ подписи и пароли. Сервер и RuStore не обновлялись.

Технические границы перечислены в CONTROL_AUDIT_0.19.md. Скорость .5 — наша настройка по замечанию игрока. Точное совпадение каждого решения нативногоИИ, группировок и коллизий не подтверждено; ежедневная доска заданий не скопирована целиком. 150 проверок логики, 12 наборовUI, 1287 файловAPK сверены. ФизическийAndroid и живая реклама здесь не проверены.
